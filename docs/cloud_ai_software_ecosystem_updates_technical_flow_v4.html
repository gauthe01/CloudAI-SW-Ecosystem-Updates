10 · Open Design Decisions

1. Can managers submit updates?

YES → simplified input form on manager view. NO → read-only. Decide before building manager page.

2. Word doc — inline edit or download only?

Inline = embedded editor (complex, V2). Download = simpler. Recommendation: download first.

3. "If all approved" gate

Cycle-level = all partners must be approved first. Per-partner = each generates independently. Per-partner more practical.

4. Duplicate detected — skip or surface?

Recommendation: surface with merge option. Skip silently risks losing signal.

5. Re-classify after edit?

Recommendation: optional "Re-classify" button. Trust human edit by default.

6. Confidence threshold values

Recommended: >0.80 auto-stage · 0.60–0.80 ask user · <0.60 reject + manual. Tune after real data.
